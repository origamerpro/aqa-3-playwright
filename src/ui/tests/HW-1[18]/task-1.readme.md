  Разработайте смоук тест-сьют с тестами на REGISTER на странице https://anatoly-karpovich.github.io/demo-login-form/

  Требования:
      Username: обязательное, от 3 до 40 символов включительно, запрещены префиксные/постфиксные пробелы, как и имя состоящее из одних пробелов
      Password: обязательное, от 8 до 20 символов включительно, необходима хотя бы одна буква в верхнем и нижнем регистрах, пароль из одних пробелов запрещен
  
  Тесты:
  1. Переход на страницу https://anatoly-karpovich.github.io/demo-login-form/
  2. Переход на вкладку REGISTER
  3. Заполнить форму
  4. Нажать кнопку REGISTER
  5. Проверить, что соответствуют требованиям логин и пароль.
  6. Проверить, что пользователь успешно зарегистрирован
  7. Проверишь, что нельзя зарегестрироваться с одинаковым логином
  8. Проверить регистрацию пользователя где username c 2 символами
  9. Проверить регистрацию пользователя где username c 41 символами
  10. Проверить регистрацию пользователя где username c префиксным пробелом
  11. Проверить регистрацию пользователя где username c постфиксным пробелом
  12. Проверить регистрацию пользователя где username, состоящий из одних пробелов
  13. Проверить регистрацию пользователя где password с 7 символами
  14. Проверить регистрацию пользователя где password с 21 символом
  15. Проверить регистрацию пользователя где password c нижним регистром
  16. Проверить регистрацию пользователя где password c одними пробелами
  17. Проверить регистрацию пользователя где password без букв
